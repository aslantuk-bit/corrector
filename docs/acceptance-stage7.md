# Приёмка Корректора на рабочем ПК

Что взять: архив `korrektor-<версия>-win64.zip` из релиза на GitHub, распаковать, папку «Корректор» записать
на флешку (или сразу на рабочий стол — так быстрее запуск).

1. Двойной щелчок по «Корректор.exe». Заставка «Запуск…», затем окно. Засечь время до окна.
   Если SmartScreen: «Подробнее» → «Выполнить в любом случае».
2. Внизу справа должно быть «LanguageTool готов». Если жёлтая плашка «Пунктуация русского недоступна» —
   прислать текст плашки автору (это ловушка Java или запрет на запуск Java).
3. «Открыть» → любой акт .docx. Проверка идёт несколько секунд. Посмотреть список замечаний: понятны ли
   сообщения, есть ли явный мусор (записать примеры).
4. Принять одно исправление кнопкой, одно вписать своё, одно пропустить, одно слово добавить в словарь.
5. «Сохранить с примечаниями» → открыть файл «имя_проверено.docx» в Word: исправления внесены, примечания
   на полях, форматирование не пострадало.
6. Проверить, что оригинальный файл не изменился (дата изменения прежняя).
7. Закрыть программу, открыть снова: слово из словаря больше не помечается.

Что прислать автору: время запуска, снимок окна, файл «имя_проверено.docx», замечания к сообщениям,
содержимое `logs/corrector.log`, если что-то падало.
